# v1.0.4

## 版本内容

- 同步 QuantumNous/new-api 上游 main 的 14 个提交，并合入 dev 的二开与修复。
- 统一普通 API 调用及下游转发的公开模型名称，使用 Root 配置的“用户上游与响应模型名称”；过滤上游供应商错误诊断和来源响应头，Root 管理端保留排障信息。
- 保留渠道文件夹与拖动排序、模型监控、仪表盘、公告和移动端布局等二开功能。
- 合入上游流式结束标记、Azure Responses WebSocket、Cloudflare embedding、渠道亲和性重试和即时任务监控等修复。
- 限制原作者 Docker Hub 工作流只在原作者仓库执行，本仓库通过 GHCR 发布镜像。

## 镜像

```text
ghcr.io/like5-ux/new-api:v1.0.4
ghcr.io/like5-ux/new-api:latest
```

支持 linux/amd64 与 linux/arm64。镜像发布后需在部署环境拉取新镜像并重新创建容器。

## 验证

- 前端受影响测试 54 项通过，类型检查、生产构建和变更文件 lint/格式检查通过。
- 后端 vet/build、独立 relaykit 验证、模型与供应商隐私、流式/WebSocket、任务提交回归通过。
