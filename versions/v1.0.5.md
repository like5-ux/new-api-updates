- 完成前端 lint 清单审查：154 条 error 修复为 0，保留 63 条非阻断写法建议；未关闭检查规则。
- 自定义页脚复用现有 HTML 过滤组件，过滤脚本、事件属性及危险链接，保留普通样式、链接和项目署名。

- 整理类型导入、条件分支和列表 key；在 PR CI 和镜像发布验证中加入全仓 lint 门禁。

## 使用镜像

```text
ghcr.io/like5-ux/new-api:v1.0.5
ghcr.io/like5-ux/new-api:latest
```

镜像支持 linux/amd64 与 linux/arm64。部署时拉取新镜像并重建容器。自定义页脚中的可执行脚本和事件属性会被过滤；需要 localStorage 或来源权限的聊天客户端可通过独立窗口打开。
